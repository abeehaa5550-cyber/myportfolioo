# Abeeha Aamir Portfolio

Premium AI automation portfolio built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run locally:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- App Router (Next.js 15)
- Dark mode by default with theme toggle
- Responsive portfolio layout
- Animated project cards and contact form
- SEO-friendly metadata and Open Graph settings
- Tailwind CSS styling and custom dark aesthetic
